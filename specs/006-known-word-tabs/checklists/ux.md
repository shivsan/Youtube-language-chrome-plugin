# UX Review Checklist: Known Word Tabs

Reviewer-owned checklist; implementation does not self-approve these judgments.

- [ ] The tab labels and counts are understandable without documentation
- [ ] Words to learn is visually clear as the default selection
- [ ] Known entries are easy to scan at the minimum supported width
- [ ] Learn again is clearer than Save for the restore action
- [ ] Success and failure feedback is noticeable without distracting from translation
- [ ] Keyboard focus order and focus styling are comfortable
- [ ] Empty states explain what each collection means
- [ ] Restoring several words in succession feels efficient
