# Side-Panel Copy Contract

## Header

- Visible: `LANGUAGE COMPANION`, current learner level, translation control.
- Not visible: `Understand every line`.
- The product name remains the document heading.

## Current caption

- Visible when applicable: playback time, `Quick translation`, translation, explanation action/result, `Original`, original caption, selected-level vocabulary summary.
- Not visible: `NOW PLAYING`, `Current translation`.
- The current-caption region remains named for assistive technology.

## Vocabulary summary

- When no estimated words exceed the selected level, the visible result is exactly `-`.

## Known-word restore

- Success updates lists/counts without a success sentence.
- Failure uses the existing status region, which occupies no space while empty.
